Publicar esta web

Una vez subida a GitHub Pages, podrás abrirla desde cualquier PC mediante una URL única. Detectará automáticamente el usuario y repositorio si se aloja en el mismo repositorio.

https://TU-USUARIO.github.io/fusion-vr-biblioteca/

El enlace será real cuando publiques los archivos y actives Pages en GitHub.

Privacidad

Un repositorio público hace accesibles sus modelos. Para modelos privados, utiliza un repositorio privado y autenticación. La futura aplicación Quest necesitará su propio método seguro de acceso.

Importante: GitHub Pages es una web públicamente accesible incluso en algunas configuraciones de repositorio privado. No introduzcas tokens en los archivos publicados.
